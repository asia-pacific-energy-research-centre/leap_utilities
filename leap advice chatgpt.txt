Do category branches return aggregated values?

LEAP’s documented results-reference behavior is:

If no filters are specified, “LEAP will return the total value of the result at the specified branch.”

So, for additive results (energy, emissions mass, many cost totals), a category branch reference implies an aggregation across its descendants consistent with the selected result variable. (For non-additive constructs like shares or intensities, “aggregation” may be a weighted calculation and is inherently variable-specific; LEAP does not document a universal rule in the public Help24 text.)

5) UnitName when blank, and ExportResultsCSV vs ExportResultsXLS differences
UnitName blank (default units)

ResultValue and ValueRS/ValueR both take an optional UnitName string. 





Help24 documents that if the bracketed unit specification is omitted in a results reference, LEAP uses the variable’s default scaling factor and units.

Therefore (documented intent): leaving UnitName blank means “return results in the default units for that variable/result,” analogous to omitting the unit portion in expression references.

ExportResultsCSV vs ExportResultsXLS (what is documented vs not)

Documented:

CSV export writes a named file in “comma separated value format (CSV).” 



XLS export exports to Microsoft Excel, with an optional sheet tab name. 



LEAP’s export dialog supports saving tables as XLS/CSV/TXT among other formats.
